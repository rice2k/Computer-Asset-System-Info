# GitHub Pages Setup

Use these settings after the repository is created on GitHub.

1. Open the repository on GitHub.
2. Go to `Settings`.
3. Open `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch.
6. Select the `/docs` folder.
7. Save.

GitHub will publish the website from:

- `docs/index.html`

The page includes screenshots, app details, feature descriptions, download notes, and release information.
