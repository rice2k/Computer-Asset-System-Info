# Publishing Notes

This folder is ready to become a GitHub repository.

Recommended publishing path:

1. Open GitHub Desktop.
2. Choose `File` then `Add local repository`.
3. Select this folder:
   `computer-asset-system-info-github`
4. Commit the files.
5. Publish the repository to GitHub.
6. On GitHub, open `Settings` then `Pages`.
7. Set Pages to publish from the `main` branch and `/docs` folder.

GitHub Desktop is recommended because the Windows executable is larger than the normal browser upload comfort zone.

Direct GitHub upload was not completed from Codex because the available GitHub tool can work with files inside an existing repository, but it cannot create a new repository here and no push-enabled matching repository was available.
